# Claude Code implementation workflow

Follow the shared repository instructions in `AGENTS.md`. Codex owns planning and scope decisions; Claude Code implements the agreed plan.

## Before implementation

1. Read `README.md`, `docs/README.md`, `docs/spec.md`, and the assigned task in `docs/tasks.md`.
2. Review relevant proposals in `docs/initial-plans.md` and notes in `docs/architecture.md` and `docs/decisions/`.
3. Confirm the task and acceptance criteria are clear. If a product or scope decision is missing, report the question to Codex for a planning update.

## Implementation

- Follow the test-first workflow and project conventions in `AGENTS.md`.
- Implement the smallest change that meets the agreed acceptance criteria.
- Do not independently change product scope, task priority, or acceptance criteria. Surface discoveries that require a planning decision.
- Update implementation documentation and task status as required by `AGENTS.md`; do not mark work complete until its criteria and required checks pass.
- Report files changed, behavior delivered, verification run, and unresolved planning questions.
