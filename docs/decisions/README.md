# Architecture decisions

Add one short Markdown file for each consequential choice, named `NNNN-short-title.md` (for example, `0001-use-postgres.md`). Keep the rationale and rejected alternatives here; keep the current design in `../architecture.md`.

Use this outline:

```markdown
# NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context
What problem or constraint prompted the decision?

## Decision
What was chosen?

## Consequences
What becomes easier, harder, or constrained?
```
